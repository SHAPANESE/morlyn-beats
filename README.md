# Morlyn Beats

Single-screen landing page for music producer Morlyn Beats. It combines a full-page WebGL CRT treatment with an interactive Three.js MPC.

## Run locally

```powershell
python -m http.server 4173
```

Then open `http://127.0.0.1:4173/`.

## Controls

- Play pads with the mouse or the keys `1–4`, `Q–R`, `A–F`, and `Z–V`.
- The first pointer or keyboard interaction unlocks browser audio.
- Instagram links to [@morlyn.beats](https://instagram.com/morlyn.beats).
